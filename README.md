# Mega 2560 +

Mega 2560+ is an upgraded version of the Arduino Mega 2560 Microcontroller. It has an on board sensor suite and an ESP32 Co-processor for WiFi, Bluetooth, and sensor reading.

---

## Key Features

- ATMEGA2560-16A Main MCU
- FM24C64C FRAM for ATMEGA
